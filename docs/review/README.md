# Review guide

This is the single registry of review rules for humans and coding agents alike. Each topic
file covers one area of the code, and its `applyTo` globs say which files it governs. When
you review a change, read only the topics whose globs match the changed files.

- Add a topic: create `docs/review/<topic>.md` with `title`, `applyTo` and `summary`
  frontmatter, then run `task review:index`.
- The table below and `.github/instructions/*.instructions.md` (GitHub Copilot review) are
  generated from the topic files. CI fails when they are stale.
